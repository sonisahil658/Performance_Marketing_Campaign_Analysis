# Performance Marketing Analysis Project

## Introduction

This project analyzes marketing campaign performance data to identify trends, optimize ad spend, and improve business decision-making.

The project includes:

```bash
Performance-Marketing-Analytics
│
├── README.md
│
├── Dataset
│   └── marketing_campaign_data.xlsx
│
├── Excel Analysis
│   ├── master_sheet.xlsx          <-- (Raw Data & Cleaning)
│   ├── pivot_analysis.xlsx        <-- (Summary Tables)
│   └── insights_sheet.xlsx        <-- (Calculated Metrics)
│
├── Power BI Dashboard
│   └── performance_dashboard.pbix
│
├── Screenshots
│   ├── dashboard-overview.png     <-- (Main Visual)
│   ├── pivot-analysis.png         <-- (Excel Pivot View)
│   ├── insights-sheet.png         <-- (Excel Calculations)
│   └── kpi-cards.png              <-- (Key Metrics)
│
└── Documentation
    └── project-overview.pdf
```

## Business Problem

Marketing teams often struggle to:
- Track campaign performance efficiently
- Compare channel effectiveness
- Monitor conversion metrics
- Optimize advertising spend

This project solves these challenges using data analytics and visualization techniques.
